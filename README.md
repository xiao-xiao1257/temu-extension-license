# Temu Edge扩展授权码仓库

本仓库保存经过数字签名的设备授权。被授权用户不需要GitHub账号，只需安装扩展、复制设备码并输入所有者返回的短授权码。

## 已部署配置

- 授权仓库：`xiao-xiao1257/temu-extension-license`
- 默认分支：`main`
- GitHub Actions：已允许写入
- 签名私钥：已保存为加密的 `LICENSE_PRIVATE_KEY` Secret
- OAuth App：新版不再使用，可以保留或手动删除

## 给用户签发授权

1. 把最终版扩展ZIP发给用户。
2. 用户安装后点击 `复制设备码`，把设备码发给你。
3. 打开本仓库 `Actions > 管理扩展授权码 > Run workflow`。
4. `operation` 选择 `issue`。
5. 填写用户设备码和到期日期，首次签发时把 `activation_code` 留空。
6. 工作流完成后，在运行摘要中复制形如 `TMU-XXXX-XXXX-XXXX` 的授权码发给用户。
7. 用户在扩展中粘贴授权码并点击 `激活授权` 即可使用。

## 续期与撤销

- 续期：再次运行工作流，选择 `issue`，填写设备码、原授权码和新的到期日期。
- 撤销：运行工作流，选择 `revoke`，填写原授权码；用户最长在24小时离线宽限结束后失效。
- 换电脑或浏览器：新安装会产生新设备码，需要重新签发新的授权码。

## 安全说明

- 授权码与设备码绑定，转发扩展或授权码到其他设备无法通过检查。
- 公开仓库只保存授权码哈希、设备码哈希和数字签名，不保存两者明文。
- 永远不要上传或转发 `OWNER_PRIVATE_KEY.pem`。
- 授权文件使用 ECDSA P-256 SHA-256 签名，手工修改会导致签名无效。
- 解压扩展的JavaScript源码对收件人可见。本方案用于阻止普通转发；如需抵御专门修改源码，核心功能必须迁移到所有者控制的服务器。
